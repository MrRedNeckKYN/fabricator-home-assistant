# Fabricator for Home Assistant

This is an **unofficial local Home Assistant add-on package** for
[Fabricator](https://fabricator.site/), release `v1.5.0` (container tag
`1.5.0`). Fabricator is a web
dashboard that installs and manages Minecraft server software; it is not a
Minecraft server or a Minecraft Java distribution by itself.

## What is persistent

Fabricator's entire `/data` directory is the add-on's persistent data volume.
That includes Minecraft server folders and worlds (`/data/servers`), server
index, managed Java runtimes, backups, Fabricator login data, and optional
playit.gg state. Do not remove the add-on's data when uninstalling if the
worlds must be retained.

## Architecture and Raspberry Pi support

The upstream image declares **amd64 and arm64/aarch64** support. This package
therefore lists only those architectures. It intentionally does **not** list
`armv7`/32-bit Raspberry Pi OS because upstream does not publish that image
architecture. Use 64-bit Home Assistant OS on a Raspberry Pi 4, Pi 5, or other
ARM64-capable Pi.

Minecraft needs considerably more memory and storage than the dashboard:

- Use a 64-bit OS and a wired network connection where possible.
- A Pi 4 with 4 GB RAM is a practical minimum for a small, lightly-modded
  server; 8 GB is preferable for newer versions or mods.
- Put Home Assistant data/worlds on reliable SSD storage, not a heavily-used
  microSD card, and keep independent backups.

## Install as a local add-on repository

1. Copy the `fabricator-home-assistant` directory to Home Assistant's
   `/addons/fabricator-home-assistant` directory (for Home Assistant OS), or
   make it available as a Git repository.
2. In **Settings → Add-ons → Add-on Store**, add the local repository/path if
   required by the installation method, reload the store, then install
   **Fabricator**.
3. Start the add-on. Open `http://HOME_ASSISTANT_IP:5000` and complete
   Fabricator's one-time operator-password setup before sharing that port.
4. In Fabricator, create a server, choose a loader/version, accept Minecraft's
   EULA when prompted, then start it. Fabricator downloads the chosen server
   implementation and the matching Java runtime itself.

The Supervisor builds a small wrapper image from the pinned upstream image; it
does not run Fabricator during installation.

## Ports and access

- `5000/tcp` is the Fabricator management dashboard. It is published by
  default. Keep it LAN-only; Fabricator has its own login, but it should not be
  exposed directly to the Internet.
- `25565/tcp` is published for one Java server using Minecraft's default
  `server-port`. Set the port mapping in the add-on Network page if it conflicts
  with another service.
- Query and RCON are disabled unless configured in the individual Minecraft
  server. They are not published by this package.
- Each additional server port must be explicitly published by a future package
  revision or accessed using Fabricator's optional playit.gg tunnel. Do not
  switch the add-on to host networking merely to avoid port mappings: that also
  makes the management dashboard broadly reachable.

## Add-on options

- `secret_key` (optional): a persistent, randomly generated Fabricator session
  signing key. Leave blank to let Fabricator generate and persist one in
  `/data/auth.json`.
- `auth_password_hash` (optional): a precomputed Fabricator password hash for
  unattended first boot. Leave blank to use the one-time setup page.
- `playit_enabled`: starts Fabricator's optional outbound tunnel agent at boot.
  A tunnel still requires the account-claim process in Fabricator.

The password hash must be generated by Fabricator (`python -m backend.auth
hash`) from a trusted local checkout/container. Do not put a plain-text
password in add-on configuration.

## Shutdown and upgrades

The wrapper delegates to Fabricator's upstream entrypoint (including `tini`)
and app process. On Home Assistant stop/restart it receives `SIGTERM`, asks
each managed Minecraft server to run its `stop` command (saving worlds), then
stops the tunnel agent. Allow the add-on to finish stopping; avoid power loss.

This package pins Fabricator `v1.5.0`. To upgrade, review the upstream release,
change the tag in both `Dockerfile` and `config.yaml`, rebuild through
Supervisor, and take a Fabricator backup first. Fabricator's self-update is
disabled inside its upstream container, which is correct for an add-on.

## Security and license

Fabricator is licensed under **GNU AGPL-3.0-or-later**. This package is only a
thin, unofficial deployment wrapper and does not change that license. It
downloads Minecraft loaders, Java runtimes, server files, mods, or modpacks at
your direction; review their licenses and sources separately. The add-on needs
outbound HTTPS for Fabricator's selected downloads (GitHub releases, Modrinth,
Adoptium, and optionally playit.gg).
