# URnetwork Provider

This add-on runs URnetwork's **official** `bringyour/community-provider` image.
It is a bandwidth-sharing provider, not a Home Assistant integration and not a
device VPN. It has no web interface and publishes no inbound ports.

## First-time setup

1. Sign in to your URnetwork account at [ur.io](https://ur.io) and generate an
   account authentication code. Prefer a code generated on the website because
   it has a longer lifetime than codes generated by mobile/desktop apps.
2. Paste it into the add-on's `auth_code` field and start the add-on.
3. After its first successful start, clear `auth_code` from the add-on options
   and save. The persistent provider identity is stored in the add-on data
   directory; the code is not needed on later starts.
4. Confirm the provider in your URnetwork account dashboard.

## Architecture, safety, and limits

- The official provider image supports ARM64/aarch64, so it is suitable for a
  64-bit Raspberry Pi 4 or Pi 5. It does not support 32-bit ARMv7 here.
- It does not need host networking, privileged mode, `/dev/net/tun`, or inbound
  ports; it connects outbound to URnetwork.
- A provider forwards other participants' traffic through your public IP.
  Review URnetwork's terms, privacy model, local laws, and your ISP's rules
  before enabling it. Stop the add-on to stop providing.
- The add-on tracks the upstream `g4-latest` (stable provider service block).
  Update it through Home Assistant when this repository releases a new package
  version.
